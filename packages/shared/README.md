# packages/shared

前后端共享的类型、schema 与常量，是跨端契约的唯一来源。

> 状态：目录已预留，包尚未初始化（M0）。

## 职责

- 设计文档 schema（节点、样式、令牌、版本迁移）。
- API 请求 / 响应 DTO 与错误码。
- Agent 工具协议与事件类型。
- 主题模式、语言列表等跨端常量。
- 纯函数形式的校验与转换工具。

## 约束

- 不依赖 React、Node.js 专有 API 或数据库客户端；保持可在浏览器与服务端运行。
- 优先使用 schema 定义并导出推导类型，避免手写类型与运行时校验脱节。
- 导出的 API 保持稳定；破坏性变更需同步前端、后端与文档。
- 附带单元测试，覆盖 schema 边界与版本迁移。

## 目录

```text
src/
├─ design/      设计文档 schema 与迁移
├─ api/         DTO 与错误码
├─ agent/       工具协议与事件
└─ constants/   主题、语言与共享常量
```
