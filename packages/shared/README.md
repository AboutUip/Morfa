# packages/shared

前后端共享的类型、契约与常量，是跨端协议的唯一来源。

> 状态：已初始化实时协议契约 · 最后更新：2026-11-26

## 职责

- 设计文档 schema（节点、样式、令牌、版本迁移）
- API 请求 / 响应 DTO 与错误码
- Agent 工具协议与事件类型
- 实时通道信封、版本与关闭码
- 主题模式、语言列表等跨端常量
- 纯函数形式的校验与转换工具

## 约束

- 不依赖 React、Node.js 专有 API 或数据库客户端；保持可在浏览器与服务端运行
- 优先使用 schema 定义并导出推导类型，避免手写类型与运行时校验脱节
- 导出 API 保持稳定；破坏性变更需同步前端、后端与文档
- 附带单元测试，覆盖 schema 边界与版本迁移

## 目录

```text
src/
├─ realtime.ts  WebSocket 信封、协议版本与关闭码
└─ index.ts     公共导出
```
