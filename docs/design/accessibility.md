# 键盘与可访问性

> 状态：已实现基础 · 最后更新：2026-11-26

## 目标

所有核心操作不依赖鼠标完成，键盘焦点不丢失、不进入不可见区域；弹窗打开后背景不可聚焦，关闭后焦点回到触发点。

## 焦点顺序

页面从顶部开始：

1. **跳到主要内容**：页面第一个可聚焦元素，回车将焦点移动到 `<main id="workspace-main">`。
2. 当前选中的顶栏 Tab（项目 / 组件 / 设置）。
3. 主题切换、语言菜单、登录 / 用户菜单。
4. 当前面板内的主要操作（如登录 / 注册）。
5. 浏览器默认焦点循环。

顶栏 Tab、弹窗内的登录 / 注册 Tab 与语言菜单选项均保留在 Tab 序列中，确保紧凑键盘或没有方向键的键盘也能完整操作；左右方向键作为快速切换方式，不替代 Tab 可达性。

## 键盘操作

| 区域 | 按键 | 行为 |
| --- | --- | --- |
| 页面 | `Tab` / `Shift+Tab` | 正向 / 反向移动焦点 |
| 页面 | `Enter` | 激活跳过链接、按钮、菜单项 |
| 顶栏 Tab | `←` / `→` | 切换项目 / 组件 / 设置 |
| 顶栏 Tab | `Home` / `End` | 跳到第一个 / 最后一个 Tab |
| 语言菜单按钮 | `↓` / `↑` | 打开菜单并聚焦第一 / 最后一个选项 |
| 语言菜单 | `↓` / `↑` | 在选项间移动 |
| 语言菜单 | `Home` / `End` | 第一个 / 最后一个选项 |
| 语言菜单 | `Enter` / `Space` | 选择语言并关闭菜单 |
| 语言菜单 | `Esc` | 关闭并返回语言按钮 |
| 登录 / 注册弹窗 | `Tab` / `Shift+Tab` | 在弹窗内循环，不进入背景 |
| 登录 / 注册弹窗 | `←` / `→` | 在登录 / 注册 Tab 间切换 |
| 登录 / 注册弹窗 | `Esc` | 关闭弹窗（提交中除外） |
| 弹窗关闭 | 自动 | 焦点回到触发弹窗的按钮 |

## 弹窗焦点管理

- 打开时焦点进入登录账号或昵称输入框。
- `#root` 设置 `inert`，背景页面与顶栏不可聚焦。
- 焦点陷阱拦截 `Tab` / `Shift+Tab`，在弹窗首尾循环。
- 点击蒙版**不关闭**，避免误触；只能通过关闭按钮或 `Esc` 退出。
- 关闭后移除 `inert`，焦点回到触发按钮；若触发按钮已因登录成功被替换，则聚焦主内容区域。
- 弹窗 Tabs 使用 `role="tablist"`、`role="tab"`、`role="tabpanel"`，并同步 `aria-selected` 与 `aria-labelledby`。
- 校验失败时自动聚焦第一个错误字段；服务端错误出现时聚焦错误提示（`tabIndex={-1}`）。
- 移动端软键盘弹出时，通过 `visualViewport` 同步 `--mf-viewport-height` 与 `--mf-viewport-offset-top`，底部弹窗保持在可视区域内并允许内部滚动。

## 语义与状态

- 页面各视图有无障碍隐藏的 `h1`，空状态使用 `h2`。
- 语言菜单使用 `menu` + `menuitemradio`，当前项 `aria-checked`。
- 加载进度使用 `role="progressbar"` 与 `aria-valuenow`。
- 表单错误使用 `role="alert"`；字段包含 `aria-invalid`。
- 图标按钮均提供 `aria-label` 或可见文本；装饰图形 `aria-hidden`。
- 全局 `:focus-visible` 提供 2px 强调色轮廓。

## 已验证

- 首个 `Tab` 命中跳过链接，回车后焦点进入主内容。
- 顶栏 Tab 全部可通过 Tab 到达，方向键、`Home`、`End` 切换正常，焦点跟随。
- 语言菜单全部选项可通过 Tab 到达，方向键、回车选择、Esc、焦点返回正常。
- 弹窗打开后焦点进入账号输入框，背景 `inert` 生效。
- 连续 `Tab` 只在弹窗内部循环，未逃逸到背景。
- 登录 / 注册 Tab 的方向键切换与后续 Tab 顺序正常。
- `Esc` 关闭弹窗后焦点回到登录按钮。
- 桌面与移动端键盘操作一致。
- 移动端软键盘适配通过 `visualViewport` 实现；真实 iOS / Android 设备仍需回归验证。
