# 键盘与可访问性

> 状态：已实现基础与 VCode 键盘交互 · 最后更新：2026-11-26

## 目标

所有核心操作不依赖鼠标完成，键盘焦点不丢失、不进入不可见区域；弹窗打开后背景不可聚焦，关闭后焦点回到触发点。

## 焦点顺序

页面从顶部开始：

1. **跳到主要内容**：页面第一个可聚焦元素，回车将焦点移动到 `<main id="workspace-main">`。
2. 当前选中的顶栏 Tab（项目 / 组件 / 设置）。
3. 主题切换、语言菜单、登录 / 用户菜单。
4. 当前面板内的主要操作（如登录 / 注册）。
5. 浏览器默认焦点循环。

顶栏 Tab、弹窗内的登录 / 注册 Tab 与语言菜单选项均保留在 Tab 序列中，确保紧凑键盘或没有方向键的键盘也能完整操作；左右方向键作为快速切换方式，不替代 Tab 可达性。

## 键盘操作

| 区域 | 按键 | 行为 |
| --- | --- | --- |
| 页面 | `Tab` / `Shift+Tab` | 正向 / 反向移动焦点 |
| 页面 | `Enter` | 激活跳过链接、按钮、菜单项 |
| 顶栏 Tab | `←` / `→` | 切换项目 / 组件 / 设置 |
| 顶栏 Tab | `Home` / `End` | 跳到第一个 / 最后一个 Tab |
| 语言菜单按钮 | `↓` / `↑` | 打开菜单并聚焦第一 / 最后一个选项 |
| 语言菜单 | `↓` / `↑` | 在选项间移动 |
| 语言菜单 | `Home` / `End` | 第一个 / 最后一个选项 |
| 语言菜单 | `Enter` / `Space` | 选择语言并关闭菜单 |
| 语言菜单 | `Esc` | 关闭并返回语言按钮 |
| 登录 / 注册弹窗 | `Tab` / `Shift+Tab` | 在弹窗内循环，不进入背景 |
| 登录 / 注册弹窗 | `←` / `→` | 在登录 / 注册 Tab 间切换 |
| 登录 / 注册弹窗 | `Esc` | 关闭弹窗（提交中除外） |
| 弹窗关闭 | 自动 | 焦点回到触发弹窗的按钮 |

## 弹窗焦点管理

- 打开时焦点进入登录账号或昵称输入框。
- `#root` 设置 `inert`，背景页面与顶栏不可聚焦。
- 焦点陷阱拦截 `Tab` / `Shift+Tab`，在弹窗首尾循环。
- 点击蒙版**不关闭**，避免误触；只能通过关闭按钮或 `Esc` 退出。
- 关闭后移除 `inert`，焦点回到触发按钮；若触发按钮已因登录成功被替换，则聚焦主内容区域。
- 弹窗 Tabs 使用 `role="tablist"`、`role="tab"`、`role="tabpanel"`，并同步 `aria-selected` 与 `aria-labelledby`。
- 校验失败时自动聚焦第一个错误字段；服务端错误出现时聚焦错误提示（`tabIndex={-1}`）。
- 移动端软键盘弹出时，通过 `visualViewport` 同步 `--mf-viewport-height` 与 `--mf-viewport-offset-top`，底部弹窗保持在可视区域内并允许内部滚动。

## 个人面板

- 点击头像打开相对屏幕水平、垂直居中的个人面板，带遮罩层；焦点进入当前 Tab。
- 个人面板通过 Portal 渲染，打开期间 `#root` 设为 `inert`，背景不可聚焦；关闭后恢复并回到头像按钮。
- 面板内 Tab、表单控件、退出登录与关闭按钮均在焦点陷阱内，首尾循环。
- `Esc`、关闭按钮或点击遮罩关闭后，焦点回到头像按钮。
- 竖向 Tab 支持上下方向键与 `Home` / `End`。
- 个人页的头像更换、昵称保存与密码修改均为可聚焦控件；账号页的导出与注销按钮同样在焦点陷阱内。
- 打开密码验证或 VCode 弹窗时暂停个人面板焦点陷阱，由弹窗接管；关闭后焦点返回触发按钮。

## VCode 弹窗

- 独立、可复用的 `VCodeModal`，使用 `role="dialog"`、`aria-modal="true"`，标题与说明通过 `aria-labelledby` / `aria-describedby` 关联。
- 3 列 × 4 行数字键盘：1–9、0，删除键位于右下角并横跨 2 列；输入 6 位后自动提交，没有额外确认按钮。
- 初始焦点落在数字 1；Tab 顺序为 1 → 9 → 0 → 删除 → 关闭，首尾循环。关闭按钮在 DOM 末尾，保证顺序稳定。
- 支持物理数字键与小键盘、`Backspace` / `Delete` 删除最后一位；`Esc` 关闭，关闭后焦点回到触发按钮。
- 点击蒙版不关闭弹窗；只通过右上角 X 或 `Esc` 退出，避免误触丢失输入。
- 验证失败时清空输入、通过 `aria-live` 播报错误，并重新聚焦数字 1；提交中禁用键盘与关闭操作。
- 弹窗相对屏幕水平、垂直居中；移动端使用 `visualViewport` 高度与安全区变量，键盘按键保持足够触控面积。

## 密码验证弹窗

- 独立、可复用的 `PasswordModal`，使用 `role="dialog"`、`aria-modal="true"`，标题与说明通过 `aria-labelledby` / `aria-describedby` 关联。
- 包含当前密码输入框、验证按钮与右上角 X；初始焦点进入输入框，Tab 顺序为输入 → 验证 → 关闭，首尾循环。
- 点击蒙版不关闭，只通过 X 或 `Esc` 退出；提交中禁用输入、按钮与关闭操作。
- 验证失败时通过 `role="alert"` 播报错误、清空输入并重新聚焦输入框；关闭后焦点返回触发按钮。
- 修改密码只需一个新密码输入框和右侧「修改」按钮；点击后先在本地校验长度，再打开密码验证弹窗，通过后完成修改。
- 注销账号按「密码验证弹窗 → VCode 弹窗」串行执行，任一步取消或失败都不会注销账号。

## 语义与状态

- 页面各视图有无障碍隐藏的 `h1`，空状态使用 `h2`。
- 语言菜单使用 `menu` + `menuitemradio`，当前项 `aria-checked`。
- 加载进度使用 `role="progressbar"` 与 `aria-valuenow`。
- 表单错误使用 `role="alert"`；字段包含 `aria-invalid`。
- 图标按钮均提供 `aria-label` 或可见文本；装饰图形 `aria-hidden`。
- 全局 `:focus-visible` 提供 2px 强调色轮廓。
