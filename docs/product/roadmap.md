# 路线图

> 状态：草案 · 最后更新：2026-11-25

路线图以「可验收的能力」而非固定日期组织。每个里程碑结束时，应能演示对应能力并更新文档。

## M0 · 仓库与文档骨架（当前）

**目标**：确定协作基础，让后续开发有明确的目录与决策依据。

- [x] monorepo 目录规划（`apps/web`、`apps/server`、`packages/shared`）
- [x] 产品、架构、设计、Agent 与开发文档骨架
- [x] 技术栈与仓库结构 ADR
- [x] 主题与 i18n 的一等能力决策
- [x] 首次提交

**退出标准**：目录职责清晰，文档可导航，关键选型有记录。

## M1 · 工程基础

**目标**：跑通最小全栈闭环，并让主题与 i18n 从第一天可用。

- npm workspaces、TypeScript、Lint / Format、测试基线
- React 应用骨架：路由、布局、错误边界
- Node.js API 骨架：健康检查、统一错误格式、日志
- SQLite 接入：迁移机制、连接配置、开发数据目录
- 主题系统：`system / light / dark` 三态、令牌、无闪烁初始化
- i18n 基础：`zh-CN` 默认、`en-US`、语言切换与持久化
- 一条端到端冒烟测试

**退出标准**：单命令启动前后端；主题与语言切换可持久化；CI 可执行构建与测试。

## M2 · 编辑器 MVP

**目标**：无需 AI 也能完成基础 UI 设计。

- 画布与图层树、选择与变换
- 基础元素：Frame、矩形、文本、图片、图标
- 属性面板、对齐与分布、样式复用
- 设计令牌与主题预览（应用主题与画布内容主题解耦）
- 项目与设计文档的创建、保存、版本
- 撤销 / 重做与快捷键体系

**退出标准**：可创建、编辑、保存并重新打开一个多页面设计；核心操作可撤销。

## M3 · Agent MVP

**目标**：用自然语言完成真实设计任务，过程可控。

- 对话面板与流式响应
- Agent 编排器、模型提供方抽象、运行记录
- 类型化设计工具集（查询、创建、修改、样式、批量操作）
- 变更预览、应用 / 放弃、撤销与运行回放
- 选区与上下文注入（当前页面、选中节点、令牌）
- 成本、速率与超时控制

**退出标准**：Agent 能在现有设计上完成一组典型任务，且每次修改可追踪、可回滚。

## M4 · 跨平台与分享

**目标**：让设计在更多设备与场景中可用。

- 响应式编辑器与触屏手势
- 分享链接、只读预览、导出（PNG / SVG / JSON）
- PWA 与离线草稿能力
- 桌面客户端方案评估与原型
- 多语言内容继续补齐（英文界面完整度）

**退出标准**：平板可完成基础编辑；分享链接可脱离账号查看。

## M5 · 上线准备

**目标**：达到公开测试质量。

- 性能预算与画布优化
- 可访问性审计与修复
- 安全审计：鉴权、上传、限流、Prompt 注入防护
- 可观测性：结构化日志、指标、错误追踪
- 备份与恢复演练
- 部署文档与运维手册

**退出标准**：完成上线检查清单，具备回滚与数据恢复能力。

## 后续候选

- 实时多人协作
- 设计系统与组件库管理
- 设计到代码（React / Tailwind 等）导出
- 插件与 Agent 工具扩展机制
- 团队计费与企业能力

> 优先级会根据用户反馈调整；调整后在本文档记录原因。
